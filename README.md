# 美文π（美文派）\- 公众号排版工具 README

## 📖 项目简介

**美文π（正式注册名：美文派）**，一款轻量化、无广告、多端互通的公众号图文排版工具。

项目以 **「无限版式，美化好文」** 为核心理念，取自数学符号 π 的无限属性，寓意为每一篇文字提供无限种精致排版可能。区别于市面臃肿、多广告、高收费的传统编辑器，主打**简洁、高效、免费易用、格式零错乱**，适配自媒体博主、运营小编、内容创作者日常图文编辑需求。

## 📱 产品形态规划

项目采用**一芯多端**架构，一套核心能力，全平台分发：

1. **网页端（主力端）**：完整编辑能力、全功能开放，适配电脑精细排版

2. **H5移动端**：适配手机浏览器，随时随地快速改稿、简单排版

3. **微信小程序**：轻量化应急编辑、模板套用、预览查看，免下载即用

4. **手机APP（后期迭代）**：全功能独立客户端，数据永久同步

## 💡 为什么做这款产品？

目前市面主流排版工具普遍存在广告泛滥、免费版带水印、操作臃肿、手机端体验极差、格式兼容性差等痛点。
**美文π（美文派）** 旨在打破行业乱象，以极简设计、纯净体验、全端适配为核心，打造一款「创作者真正需要的排版工具」，让排版不再是负担，让每一篇好文都值得精致呈现。
